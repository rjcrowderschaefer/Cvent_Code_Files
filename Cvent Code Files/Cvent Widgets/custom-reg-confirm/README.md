# custom-reg-confirm

Same code as `custom-reg-pages`, uploaded as a second Cvent widget with purpose
`Website` so it can be placed on pages that don't list `General` widgets (the
"Registration Pending Approval" page). In the editor, set "What this copy shows"
to Confirmation.

Keep the .js files identical to `custom-reg-pages`: copy them over after every
change there (only config.json differs).
